# 周边小仓库

中文个人周边库存管理，适配手机。独立用户名密码、邀请码注册，每个账号拥有独立的云端库存、销售、分类和图片。支持成员数量、分批成本、部分售出、邮费分摊、整单撤销、图片备份及空仓库导入。

**GitHub 是代码和自动部署入口。GitHub Pages 无法运行账号和数据库接口，本项目部署到 Cloudflare Workers + D1（图片也存D1）。**

仓库只包含程序，不含任何个人库存、照片、密码、初始化密钥或数据库副本。请勿将备份上传到 GitHub。

## 部署方式

当前采用 Cloudflare Workers 的 GitHub 集成自动部署，推送到 main 后自动更新。

- 项目名：`merch-inventory`
- 构建命令：`npm test`
- 部署命令：`npx wrangler d1 migrations apply DB --remote && npx wrangler deploy`
- 禁用预览构建，避免预览环境接触正式数据库。
- D1数据库绑定为`DB`。图片存入D1分块表，不需要开通R2订阅。

GitHub Actions 同时进行测试和打包检查；可选的 Actions 部署只有配置 Cloudflare variables/secrets 后才启用，当前使用 Cloudflare 自带部署，不必配置该途径。

## 管理员首次设置

管理员使用单独保管的一次性随机密钥创建自己的用户名和密码。仓库中的 `ADMIN_SETUP_HASH` 仅为该高强度密钥的SHA-256校验值，不能直接用于登录。密钥原文绝不能提交到仓库。初始化完成后此入口关闭，测试者通过管理员生成的邀请码注册。

如果复用这个仓库创建另一套应用，应重新生成随机密钥与对应校验值，不能复用原管理员的密钥。已有账号不会因更新该校验值而重置。

## 原数据迁移

原网站与新网站是两份独立数据库，不会自动同步。

1. 在原网站点击“下载完整备份”，获得包含图片的 JSON 文件。
2. 登录新网站管理员账号，打开“我的账号 → 从旧仓库迁移”，选择文件并导入。
3. 导入仅允许空仓库且文件最大11MB，不覆盖已有记录。核对数量、成本和销售后，再统一使用新网址。
4. 保留原网站和下载的备份作为回退。此仓库没有包含任何人的原始数据。

## 账号与数据

- 每个邀请码7天内有效，只能注册一次；管理员可以撤销未使用的邀请码。
- 新用户从空白仓库开始。账号管理只显示昵称及状态，不显示其他人的库存。
- 停用会退出该账号所有设备，保留数据；重新启用后可以再次登录。
- 修改密码需要当前密码，并退出其他设备。暂不支持邮件找回，请保存到密码管理器。
- 云端记录按账号隔离，本地备份包含自己的图片和记录。
- 不要将数据库或备份文件上传到代码仓库。

## 本地开发

需要 Node.js 22。

```sh
npm ci
npm run db:local
# 管理员初始化密钥原文仅保存在自己的密码管理器/本地私密文件
npm run dev
npm test
npm run check
```

`wrangler.jsonc` 绑定正式数据库；`wrangler dev` 和 `--local` 使用独立本地数据库。请勿在测试命令中使用 `--remote`。

## 费用与维护

使用量、套餐与计费由 Cloudflare 决定。上线前检查其控制台提示和额度。请定期下载备份。此版本适合个人收藏和小规模邀请测试，暂不提供自助密码找回、删除账号或离线编辑。

参考：[Cloudflare Workers 静态资源与API](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/)、[D1迁移](https://developers.cloudflare.com/d1/reference/migrations/)。

## v2.0（2026-10-23）

- 录入与显示设置按账号保存：简易/详细模式、显示成本利润开关。新账号默认简易模式，成本利润默认隐藏。旧账号保持详细录入。
- 简易录入只必填名称、数量。日期留空自动记录今天（上海时区），位置备注可空。成本留空时 cost_known=false；0 是已知零成本。涉及未知成本的销售不展示利润。
- 批量支持 UTF-8 CSV/Excel Tab，按表头映射。最少名称、数量；可选类型/系列/角色/单件成本或总成本/入库日期/位置/备注。先服务器校验预览，最后原子保存到个人仓库。
- 共享图库需管理员在“共享卡图库→从我的库存分享卡图”明确选择。仅投影分类、系列、角色、成员顺序、图片；不分享个人物品名称、备注、数量、金额、位置。没有自动上传本地私人图片或库存。选择共享卡款或精确系列角色匹配后带入图片；歧义时要求手动选择。
- 管理员可下架图片，新入库不能再选；已引用该卡图的个人库存仍能查看和备份。下架不从其他账号删除已经引用的图片。
- 没有接入收费 AI，图片识别仍在对话中进行。完整备份包含成本和图片，普通 CSV 遵循显示开关。
