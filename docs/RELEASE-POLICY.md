## 四段产品版本 A.B.C.D

| 段 | 升级范围 | 示例 |
| --- | --- | --- |
| A | 整体架构或产品重大变化 | 2.x.x.x → 3.0.0.0 |
| B | 新增独立功能模块 | 2.7.x.x → 2.8.0.0 |
| C | 现有功能增加一组较完整能力 | 2.7.0.x → 2.7.1.0 |
| D | 问题修复、局部布局/紧凑度调整、提示文字等小修改 | 2.7.1.1 → 2.7.1.2 |

升级高位时，所有低位归零。一次正式发布可包含多项修改，按最大实际范围只递增一次相应版本。开发提交、测试与预览不反复升级正式版本；小修改不能反复升级第二段。
